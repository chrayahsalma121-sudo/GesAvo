⚖️ Law Firm Management App (React + Tailwind CSS)

A modern Law Firm Management Web Application built with React and styled using Tailwind CSS.
This project provides a clean, scalable foundation for managing legal operations such as cases, clients, hearings, and documents — with support for Arabic UI and a dark theme.

🚀 Features
🌙 Dark Mode UI (gold / brown / beige theme)
🌍 Arabic-friendly interface (RTL-ready structure)
⚛️ Built with React (v19)
🎨 Styled using Tailwind CSS
📁 Modular and scalable project structure
⚡ Fast development with react-scripts
📁 Project Structure
law-firm-app/

🛠️ Technologies Used
React – Frontend library
Tailwind CSS – Utility-first CSS framework
PostCSS & Autoprefixer – CSS processing
React Scripts – Development environment
⚙️ Installation & Setup
1. Clone the repository
git clone <your-repo-url>
cd law-firm-app
2. Install dependencies
npm install
3. Run the development server
npm start

The app will run at:

http://localhost:3000
📦 Available Scripts
npm start → Run the app in development mode
npm run build → Build for production
npm test → Run tests
npm run eject → Eject configuration (advanced)
🎨 Tailwind Configuration

Tailwind is fully integrated via:

tailwind.config.js

Colors (dark gold / brown theme)
